## 1. 抖音小游戏接入总览

### 1.1 接入前置资质

## 2. tt.login 登录接入

### 2.1 流程

```
客户端启动 → 平台适配层调 tt.login 获取 code
→ POST /auth/login {code} → 后端用 AppSecret 调抖音 code2session
→ 换取 openid/session_key → 注册/登录 gd_user → 下发自有 token
→ 客户端保存 token，后续请求携带
```

### 2.2 客户端代码（TypeScript）

```typescript
// 平台适配层：douyinLogin.ts（抖音端实现）
// 接口声明见 05 文档 PlatformAdapter，微信/H5 各自实现同一接口

export interface LoginResult {
  code: string;        // 抖音登录凭证
  anonymous?: boolean; // 是否匿名登录（用户拒绝授权时兜底）
}

export function douyinLogin(): Promise<LoginResult> {
  return new Promise((resolve, reject) => {
    tt.login({
      success: (res: { code: string }) => resolve({ code: res.code }),
      fail: (err: { errMsg: string }) => reject(new Error(`tt.login failed: ${err.errMsg}`)),
    });
  });
}

// 登录服务：loginService.ts
export async function loginToGame(baseUrl: string): Promise<string> {
  const { code } = await douyinLogin();
  const resp = await fetch(`${baseUrl}/auth/login`, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ code, platform: 'douyin' }),
  });
  const data = await resp.json();
  if (!resp.ok) {
    throw new Error(`login failed: ${data.code} ${data.message}`);
  }
  // data: { token, expires_in, is_new, is_minor, user }
  tt.setStorageSync('gd_token', data.token);
  return data.token;
}
```

### 2.3 后端要点

- `POST /auth/login`：NestJS 侧用 `AppSecret` 调抖音 `code2session` 接口换 openid；**AppSecret 绝不进客户端代码**。
- `gd_user` 唯一约束 UK(openid)，新 openid 自动注册并返回 `is_new`（用于埋点 `login_success` 与新手引导）。
- `is_minor`：从抖音侧年龄能力或用户自填获取，写入 `gd_user`，驱动 09 文档的未成年广告频控与 IAP 关闭。
- token 有效期 7 天（Redis `gd:session:{token}`），过期静默刷新登录，不打断游戏。

### 2.4 异常与兜底

| 场景 | 处理 |
| --- | --- |
| 用户拒绝授权 / tt.login 失败 | 进入匿名模式：生成本地临时 uid，仅上报匿名埋点，功能受限（无存档云同步、无广告） |
| code2session 失败 | 后端返回可重试错误码，客户端指数退避重试 3 次后提示"网络异常" |
| token 过期 | 客户端 401 时静默调 tt.login 换新 token 重放请求 |

## 3. 激励视频广告接入

### 3.1 广告位映射

| 点位 | ad_type | ad_unit_id 命名建议 |
| --- | --- | --- |
| 提示 | hint | `gd_hint` |
| 失败复活 | revive | `gd_revive` |
| 双倍奖励 | double | `gd_double` |
| 隐藏线索 | clue | `gd_clue` |

> 4 个 ad_unit_id 在抖音开发者后台单独创建；ad_unit_id 属于平台配置，通过服务端配置下发（`GET /config/ad`），不进客户端源码硬编码清单（见 09 合规）。

### 3.2 客户端代码（TypeScript）

```typescript
// 广告服务：adService.ts
// 遵循 09 文档：奖励只认服务端 ad/verify 结果，客户端不直接发奖

interface AdUnitConfig {
  adType: 'hint' | 'revive' | 'double' | 'clue';
  adUnitId: string;
}

const adCache = new Map<string, any>(); // adType -> RewardedVideoAd 实例

function getAd(adType: string, adUnitId: string): any {
  if (adCache.has(adType)) return adCache.get(adType);
  const ad = tt.createRewardedVideoAd({ adUnitId });
  ad.onError((err: { errMsg: string }) => {
    console.error(`[ad:${adType}] load error`, err.errMsg);
    // 埋点 ad_error
  });
  adCache.set(adType, ad);
  return ad;
}

/** 播放激励视频：先开广告会话（/ad/start），onClosed(isEnded=true) 后带回调凭证走服务端验证 */
export function playRewardedAd(
  cfg: AdUnitConfig,
  scene: string,
  levelId: string,
  baseUrl: string,
): Promise<{ granted: boolean; reward?: string }> {
  return new Promise((resolve, reject) => {
    // ① 请求后端开启一次广告会话（防自造请求），返回一次性 ad_token
    fetch(`${baseUrl}/ad/start`, {
      method: 'POST',
      headers: { Authorization: `Bearer ${tt.getStorageSync('gd_token')}` },
      body: JSON.stringify({ ad_type: cfg.adType, scene, level_id: levelId }),
    })
      .then((r) => r.json())
      .then(({ ad_token }) => {
        const ad = getAd(cfg.adType, cfg.adUnitId);
        ad.show()
          .catch(() => {
            // 加载失败重试一次，仍失败则拒绝
            return ad.load().then(() => ad.show());
          })
          .then(() => {
            // ③ 播放中等待 onClose
            ad.onClose((res: { isEnded: boolean }) => {
              // 埋点 ad_watch（无论是否看完）
              reportAdWatch(cfg.adType, scene, levelId, res.isEnded);
              if (!res.isEnded) {
                resolve({ granted: false }); // 未看完不发放
                return;
              }
              // ④ 走服务端验证发放：ad_token + 抖音回调凭证（ad_type/scene/level_id 由服务端从会话关联）
              fetch(`${baseUrl}/ad/verify`, {
                method: 'POST',
                headers: { Authorization: `Bearer ${tt.getStorageSync('gd_token')}` },
                body: JSON.stringify({
                  ad_token,
                  platform_order_id: adOrderId, // 抖音 SDK 回调凭证（orderId/transId，字段名以平台文档为准）
                  ad_unit_id: cfg.adUnitId,
                }),
              })
                .then((r) => r.json())
                .then((data) => {
                  if (data.granted) resolve({ granted: true, reward: data.reward });
                  else resolve({ granted: false });
                })
                .catch((e) => reject(e));
            });
          })
          .catch((e) => reject(e));
      })
      .catch((e) => reject(e));
  });
}
```

### 3.3 关键约束（与 09 一致）

- 奖励发放**只认** `POST /ad/verify` 服务端结果（服务端调抖音服务端验证接口校验回调，写 `gd_ad_reward`，verify_status 流转）。
- `isEnded=false`（中途关闭）一律不发放，不重试（防刷）。
- 广告异常（ad_error）时展示"广告加载失败，请稍后再试"，不给替代奖励。
- 频控在服务端强制：超限时 `ad/start` 直接拒绝并返回明确错误码，客户端隐藏按钮并展示"今天看够啦，明天再来"。

## 4. 分享能力

### 4.1 分享卡片接入

```typescript
// 分享服务：shareService.ts
export interface SharePayload {
  title: string;          // 分享文案
  imageUrl?: string;      // 分享图（视频封面/通关分享图）
  query?: string;         // 携带参数，如 level=37&uid=gd_u_102488
}

export function shareToDouyin(payload: SharePayload): Promise<boolean> {
  return new Promise((resolve) => {
    tt.shareAppMessage({
      title: payload.title,
      imageUrl: payload.imageUrl,
      query: payload.query || '',
      success: () => resolve(true),   // 埋点 share_success
      fail: () => resolve(false),
    });
  });
}

// 调用示例：结算页分享
shareToDouyin({
  title: '我卡在第 37 关 3 次了，你敢来试试吗？', // 与传播文案库联动（第 7 章）
  imageUrl: shareImageUrl,                        // 通关分享图（第 6 章生成）
  query: `level=37&uid=${userId}`,
});
```

### 4.2 分享回调与归因

- `tt.onShow` 中解析启动参数 `query`，识别 `open_from_share`（埋点，属性带 source_level、share_uid、is_new）。
- 分享带来的新用户：进入后自动跳转到 source_level（若未解锁则落到最近解锁关），并在该关播放"好友 Bug 哥在此关卡壳"彩蛋口播，形成社交钩子。
- 归因落地：`share_success` → `open_from_share` → `app_launch(launch_from=share)` 三段事件串成回流漏斗（10 文档 3.3 节联动）。

## 5. 开放数据域与排行榜接入

### 5.1 开放数据域用途

- 主域（游戏逻辑）与开放数据域（好友排行）隔离，开放数据域只能访问好友数据接口。
- 用于「好友通关排行」「好友卡关挑战」两个场景（对应 `rank_view`、`rank_click_share` 埋点）。

```typescript
// 开放数据域代码（openDataContext 内运行，单独入口文件）
tt.onMessage((msg: any) => {

    tt.getFriendCloudStorage({

            score: (item.KVDataList[0] && item.KVDataList[0].value) || '0',
```

### 5.4 约束

- 开放数据域代码与主域**完全隔离**：开放数据域内不得 require 主域模块，主域不得在开放数据域内调用 tt.login/广告等受限 API。
- 好友数据仅用于排行展示，不落业务库；业务级全量排行走服务端 Redis ZSet（`gd:rank:*`，见 07 文档）。
- 开放数据域渲染用独立 canvas，性能受平台限制，列表虚拟化渲染（一次只画可视区行）。

## 6. 通关分享图生成

### 6.1 方案：主域 Canvas 离屏绘制 + 保存

```typescript
// 分享图生成：shareImageService.ts
// 尺寸建议：750 x 1334（竖版 9:16），适配抖音分享卡片与相册保存

export interface ShareImageData {
  levelNo: number;
  timeText: string;      // 完成时间文案，如 "1 分 32 秒"
  skinKey: string;       // 当前皮肤（programmer/detective/chef/ancient）
  isChallenge: boolean;  // 是否挑战模式（每日挑战）
}

export function generateShareImage(data: ShareImageData): Promise<string> {
  return new Promise((resolve, reject) => {
    const canvas = tt.createCanvas();
    canvas.width = 750;
    canvas.height = 1334;
    const ctx = canvas.getContext('2d');

    // 1. 背景（品牌渐变 + 网格质感，商用级审美）
    const grad = ctx.createLinearGradient(0, 0, 0, 1334);
    grad.addColorStop(0, '#1a1f3d');
    grad.addColorStop(1, '#0d1030');
    ctx.fillStyle = grad;
    ctx.fillRect(0, 0, 750, 1334);

    // 2. 主标题
    ctx.fillStyle = '#ffffff';
    ctx.font = 'bold 64px sans-serif';
    ctx.textAlign = 'center';
    ctx.fillText('Bug哥挑战', 375, 300);

    // 3. 关卡信息
    ctx.fillStyle = '#ffd166';
    ctx.font = 'bold 120px sans-serif';
    ctx.fillText(`第 ${data.levelNo} 关`, 375, 480);

    // 4. 完成时间
    ctx.fillStyle = '#e8eaf6';
    ctx.font = '44px sans-serif';
    ctx.fillText(`完成时间：${data.timeText}`, 375, 620);

    // 5. 挑战标签（每日挑战模式）
    if (data.isChallenge) {
      ctx.fillStyle = '#ef476f';
      ctx.beginPath();
      ctx.roundRect(285, 680, 180, 64, 16);
      ctx.fill();
      ctx.fillStyle = '#ffffff';
      ctx.font = 'bold 36px sans-serif';

    ctx.fillStyle = '#8bd3ff';
    ctx.font = '36px sans-serif';
    ctx.fillText(`穿的是「${skinName(data.skinKey)}」`, 375, 820);

    // 7. 底部引导（传播钩子）
    ctx.fillStyle = '#ffd166';
    ctx.font = 'bold 44px sans-serif';
    ctx.fillText('99% 的人卡在第 37 关', 375, 1100);
    ctx.fillStyle = '#ffffff';
    ctx.font = '36px sans-serif';

    ctx.fillText('长按识别，来挑战 Bug 哥', 375, 1250);

    // 8. 保存为临时文件路径
    tt.canvasToTempFilePath({
      canvas,
      success: (res: { tempFilePath: string }) => resolve(res.tempFilePath),
      fail: (err) => reject(err),
    });
  });
}

function skinName(key: string): string {
  const map: Record<string, string> = {
```

## 7. 传播闭环设计

### 7.1 传播链路总览

```
抖音短视频（99% 卡在第 37 关）→ 评论区/链接进入小游戏
→ 新用户首关 → 卡在第 37 关（高卡关率关卡 = 天然话题）
→ 看广告提示 / 通关 → 生成通关分享图 → 分享到抖音/好友
→ 好友 open_from_share 回流 → 新增用户 → 循环
```

### 7.2 各环节设计

| 环节 | 设计 | 指标挂钩 |
| --- | --- | --- |
| 短视频素材 | 三条固定标题：「99%的人卡在第37关」「答案就在你眼前」「只有细心的人能发现」；第 37 关必须是"视觉误导型"代表关，适合 15s 短视频展示反转 | app_launch(launch_from=douyin_card) |
| 小游戏承接 | 从短视频进入的首个关卡即展示"Bug哥"角色魅力，前 3 关无广告（09 文档 2.2） | 首关完成率 |
| 卡关话题化 | 第 37 关刻意保持高卡关率（难度曲线设计，见 03/04 文档），成为社交货币 | 卡关率 + share_click |
| 通关分享图 | 第 6 章方案，图上自带传播文案与关卡信息，形成"行走的广告位" | share_image_save |
| 好友回流 | 分享带 query 参数归因，回流用户直接进入 source_level 并触发"好友在此卡壳"彩蛋 | open_from_share |
| 持续运营 | 每周投放新短视频素材（卡关点轮换：37 → 63 → 88），与关卡更新节奏同步 | 7 日留存 + 新增 |

### 7.3 关键传播指标

| 指标 | 定义 | 目标 |
| --- | --- | --- |
| 分享率 | 当日分享成功用户 / DAU | ≥ 8% |
| 分享回流率 | open_from_share 用户 / 分享成功次数 | ≥ 5%（分享带新人） |
| 分享图保存率 | share_image_save / share_image_generate | ≥ 30% |
| 短视频转化 | douyin_card 进入 → 完成首关 | ≥ 60% |
| K 因子 | 分享回流新增 / DAU | ≥ 0.05 即可形成自增长 |

## 8. 合规与审核红线

| 红线 | 要求 | 违反后果 |
| --- | --- | --- |
| 诱导分享 | 禁止"分享才可过关/分享得奖励"强诱导；分享按钮不得做成"必点" | 审核驳回 / 下架 |
