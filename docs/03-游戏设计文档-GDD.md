## 1. 核心玩法与流程

### 1.1 一句话玩法

玩家在 Bug 哥的引导下，发现现实场景中的「小 Bug」（视觉误导、常识反转、目标误解、语言陷阱、细节推理），
通过改变思考方式获得 Aha Moment（恍然大悟）。所有谜题答案都符合现实逻辑，禁止魔法、随机答案与作者强行解释。

### 1.2 核心循环（铁律）

```
发现异常 → 按常识解决 → 思路错误 → 重新观察 → 找到隐藏逻辑 → 恍然大悟
```

拆解为可运营的循环：

```
┌──────────┐  发现异常   ┌──────────┐  按常识操作  ┌──────────┐
│ 场景呈现   │ ────────→ │ Bug哥开场 │ ──────────→ │ 玩家试错   │
└──────────┘            └──────────┘             └────┬─────┘
                                                      │ 错误（误导层）
     ┌────────────────────────────────────────────────▼──────┐
     │ 失败反馈：Bug哥吐槽 + 错误计数 + 屏幕轻震 + 错误音效     │
     └────────────────────────────────────────────────┬──────┘
                                                      │
        ┌─────────── 提示系统（1/2/3 级）与「调查」能力介入 ←───┘
        ▼
   ┌──────────┐  重新观察   ┌──────────┐  正确交互   ┌──────────┐
   │ 换思路     │ ────────→ │ 找到隐藏逻辑│ ─────────→ │ Aha动画   │
   └──────────┘            └──────────┘             └────┬─────┘
                                                         ▼
                                                 真相揭晓 + 结算
                                                 （星级/Bug日志/剧情）
```

### 1.3 单局流程

| 阶段 | 内容 | 时长目标 |
| --- | --- | --- |
| 进入关卡 | 场景淡入，Bug 哥开场白（埋误导钩子），目标提示「找出 Bug」 | 1-3 秒 |
| 误导层 | 玩家按常识交互，命中错误动作，Bug 哥帮腔吐槽 | 0-90 秒 |
| 重新观察 | 提示系统与「调查」能力介入，缩小搜索范围 | 10-60 秒 |
| 真相层 | 命中正确动作，Aha 动画，真相揭晓，Bug 哥认错 | 2-5 秒 |
| 结算 | 星级、Bug 日志解锁、剧情推进、分享、激励视频双倍奖励 | 3-6 秒 |

### 1.4 交互系统总览

关卡解释器支持 5 种交互触发器（trigger），Schema 定义见 docs/04：

| 触发器 | 操作 | 典型用法 |
| --- | --- | --- |
| tap | 单击物件 | 检查物件、触发状态切换 |
| doubleTap | 双击物件 | 放大查看细节（配合「调查」能力） |
| longPress | 长按物件 | 隐藏机关、彩蛋触发 |
| drag | 拖拽物件 | 移动物件到指定区域（dragTo） |
| combine | 将 A 物件拖到 B 物件上 | 组合操作（把硬币放进售货机） |

### 1.5 胜负与星级

| 条件 | 星级 |
| --- | --- |
| 错误 ≤ 2 次且未用提示 | ★3 |
| 错误 ≤ 4 次，或使用过 1 级提示 | ★2 |
| 通关即可（使用过 2 级以上提示，或错误 > 4 次） | ★1 |

- 错误次数：命中「误导层动作」即 +1；命中「无意义动作」不计错但给轻提示文案。
- 星级影响：星级累加解锁章节套装奖励与隐藏关门槛（见第 7 章）。

## 2. 每关标准结构（误导层 → 真相层 → Aha）

所有关卡遵循统一四阶段结构，关卡 JSON 中 `misleadLayer` 与 `truthLayer` 分别承载阶段 1 与阶段 3（见 docs/04）。

### 阶段 0 · 进入（场景建立）

- 场景淡入，展示物件与氛围音效。
- Bug 哥开场白包含 1 个「误导钩子」——一句把玩家引向常识思路的话。
- 顶部显示目标：「找出 Bug」。

### 阶段 1 · 误导层（按常识解决 → 思路错误）

- 玩家按常识操作，命中 `misleadLayer.actions` 中的错误动作。
- 反馈：错误音效 + 屏幕轻震 + Bug 哥吐槽台词（吐槽内容强化误导方向）。
- 错误计数 +1；2 次错误后 Bug 哥台词升级为「动摇版」，暗示玩家思路不对。

### 阶段 2 · 重新观察（提示分档介入）

- 1 级提示：指出「别相信第一眼」（泛提示）。
- 2 级提示：缩小范围（指向可疑物件）。
- 3 级提示：直接点破真相逻辑（但不说操作）。
- 配合「调查」能力（双击放大、慢放动画）辅助观察。

### 阶段 3 · 真相层（找到隐藏逻辑 → Aha）

- 命中 `truthLayer.actions` 中的正确动作。
- Aha 动画序列：画面定格 → 快速左右抖动 2 次 → 灯泡爆亮 → 回放「误导瞬间 vs 真相瞬间」对比。
- 真相文案揭晓 + Bug 哥认错台词（铁律台词库轮换）。
- Bug 日志解锁。

### 阶段 4 · 结算

- 星级展示、通关时间、Bug 日志收藏卡片、剧情推进。
- 分享按钮 + 激励视频点（双倍金币）。

## 3. 五类谜题详解

> 每类谜题给出：定义、玩家心智模型（为什么会被误导）、设计要点、2 个完整可玩示例关卡。
> 示例关卡统一包含：关卡编号、难度星级、Bug 日志编号、场景、物件、误导层、真相层、Bug 哥台词、Aha 设计。

### 3.1 视觉误导（puzzleType: visual）

**定义**：利用视觉感知偏差（透视、颜色、大小、明暗、重叠）让玩家得出错误结论。真相符合物理与现实，只是「眼睛骗了你」。

**心智模型**：玩家默认「所见即所得」——看到灯泡亮就以为灯开着、看到大就以为近、看到影子就以为有东西。

**设计要点**：
1. 误导必须来自画面本身，不能来自文案（否则归入语言陷阱）。
2. 真相揭晓后要有「回放对比」，让玩家看见自己错在哪一帧。
3. 每关最多 1 个视觉机关，避免画面信息过载。

#### 示例关卡 1：《关掉的灯还亮着》

- 关卡编号：1（第 1 关）｜难度：★2｜Bug 日志：Bug001｜章节：01 家中
- **场景**：深夜卧室。靠窗床头柜上放着一盏「台灯」，光线柔和发亮；墙上开关处于「关闭」状态（拨杆朝下）；窗外是夜晚。
- **物件清单**：台灯（亮、可 tap）、开关（关闭态、可 tap）、窗户（可 drag 拉开窗帘）、闹钟（干扰物，可 tap）。
- **误导层**：
  - 玩家认为「灯亮着开关却关着 = Bug」，于是点开关（错误）：Bug 哥吐槽「开关我都关了啊，这灯怕不是成精了？」
  - 玩家点台灯（错误）：Bug 哥吐槽「别摸！烫手算谁的？这绝对是灯坏了。」
- **真相层**：把窗帘拉开（drag 窗户）→ 窗外月光照进来 → 玩家发现「台灯」其实没通电，那点亮光是窗外的月亮反射在灯罩上。
- **Bug 哥台词**：
  - 开场：「你看这灯，开关明明关着，它却亮着——这不就是 Bug 吗？修它！」
  - 真相：「等等……好像问题不在灯，在我的眼睛。月亮，你礼貌吗？」
  - 招牌台词掉落：「这不是 Bug，这是隐藏功能——月光充电台灯。」
- **Aha 设计**：回放对比——左侧「灯亮」瞬间，右侧窗帘拉开后月光路径连线，玩家看到光的真实来源。

#### 示例关卡 2：《巨大的猫》

- 关卡编号：12｜难度：★2｜Bug 日志：Bug012｜章节：02 办公室
- **场景**：办公室走廊。近处一只小橘猫蹲在镜头前，远处办公桌后坐着一个「很小的人」。
- **物件清单**：橘猫（近景，可 tap）、远处小人（可 tap）、走廊尽头的门（可 tap）、墙上的灭鼠标语（干扰物，可 tap）。
- **误导层**：
  - 玩家以为「人变小了 = Bug」，点小人（错误）：Bug 哥吐槽「他要是缩水了，我第一个报警。」
  - 玩家以为「猫巨大化 = Bug」，点猫（错误）：Bug 哥吐槽「好家伙，这猫是不是吃了袋鼠？」
- **真相层**：点走廊尽头的门 → 镜头切换为侧视 45 度 → 透视关系一目了然：猫在近处所以大，人在远处所以小，纯透视。
- **Bug 哥台词**：
  - 误导时：「问题大了！这办公室闹巨人症了……哦不对，闹缩骨症了！」
  - 真相：「原来真正的 Bug 是我的思维——近大远小，我小学美术课睡过去了？」
- **Aha 设计**：镜头推拉动画，从「正面」旋转到「侧面 45 度」，透视线实时绘制。

### 3.2 常识反转（puzzleType: reverse）

**定义**：玩家按正确常识操作，但现实逻辑在这个场景里「反着来」。真相依然符合物理规律，只是玩家忽略了一个关键条件。

**心智模型**：玩家带着「教科书答案」进入关卡（热了就开空调、渴了就喝水），忽视场景中的反例条件。

**设计要点**：
1. 反转必须有一个「可解释的原因」（冰箱开门会让房间变热，因为热量被搬到屋里）。
2. 误导钩子台词要「帮玩家确认常识」，让玩家更自信。
3. 真相揭晓后补充一句「科学小贴士」，强化「原来如此」。

#### 示例关卡 3：《越开越热的空调》

- 关卡编号：18｜难度：★2｜Bug 日志：Bug018｜章节：02 办公室
- **场景**：夏天闷热的办公室。窗户紧闭，一台空调对着墙上的电暖器吹冷风；温度计显示 33 度。
- **物件清单**：空调遥控器（可 tap 调节）、温度计（可 tap）、电暖器（已通电亮红灯，可 tap）、窗户（可 drag）、空调内机（可 tap）。
- **误导层**：
  - 玩家按常识把空调调低到 16 度（错误）：Bug 哥吐槽「16 度了还热？这空调怕是改行做电吹风了！」
  - 玩家反复调遥控器（错误）：Bug 哥吐槽「再按下去遥控器都要按出火星了，温度倒是涨了。」
- **真相层**：关掉电暖器（tap 电暖器）→ 温度计回落到 26 度。真相：空调吹冷风时被电暖器的热辐射抵消，制冷能力被「加热器」对冲。
- **Bug 哥台词**：
  - 误导时：「不可能！科学不会骗我！空调 16 度天下无敌！」
  - 真相：「等等，好像问题在我——空调再努力，也扛不住旁边那个 2000 瓦的『内鬼』啊。」
  - 科学小贴士：「电暖器在空调下方，热空气上升，冷气全被『烤』掉了。」
- **Aha 设计**：温度计数值实时动画，关闭电暖器瞬间数值断崖式下降，热空气上升路径可视化。

#### 示例关卡 4：《冒泡的锅》

- 关卡编号：6｜难度：★2｜Bug 日志：Bug006｜章节：01 家中
- **场景**：厨房。燃气灶没开火，灶上的锅却在咕嘟咕嘟冒泡，热气腾腾。
- **物件清单**：锅（冒泡，可 tap）、燃气灶旋钮（关闭态，可 tap）、旁边的可乐瓶（可 tap）、菜刀（干扰物，可 tap）。
- **误导层**：
  - 玩家以为「灶开着却看不见火 = Bug」，拧旋钮（错误）：Bug 哥吐槽「火都关死了还冒气？这锅怕不是成精了。」
  - 玩家点锅盖想揭锅（错误）：Bug 哥吐槽「别！万一里面是个火山口呢？」
- **真相层**：点旁边的可乐瓶 → 镜头切近景：锅里倒的是整瓶刚倒进去的可乐，冒泡的是碳酸气泡，不是水蒸气。
- **Bug 哥台词**：
  - 误导时：「破案了！这锅烧的是空气！煤气公司得给我道歉！」
  - 真相：「原来真正的 Bug 是我的思维——可乐不冒泡，那才叫 Bug 吧？」
- **Aha 设计**：镜头拉近锅面，气泡逐颗放大成「碳酸气泡」字样贴纸，与旁边可乐瓶形成连线。

### 3.3 目标误解（puzzleType: target）

**定义**：玩家找错了「要修的对象」。场景中有多个「异常」，真正要处理的和最显眼的不是同一个。

**心智模型**：玩家默认「最显眼的异常 = 目标」，被画面中心/最大/最吵的物件吸引，忽略角落里的真目标。

**设计要点**：
1. 假目标必须「真的有问题但无伤大雅」，真目标必须「不起眼但致命」。
2. 玩家对假目标操作时，Bug 哥要「配合演出」却始终不修好，制造反差。
3. 结算时列出「假目标排查记录」，强化成就感。

#### 示例关卡 5：《修错的那台电脑》

- 关卡编号：25｜难度：★3｜Bug 日志：Bug025｜章节：03 街道·网吧
- **场景**：网吧。一台显示器黑屏（最显眼），隔壁的电脑主机机箱侧板开着、风扇停转；墙上的时钟停在 3 点。
- **物件清单**：黑屏显示器（可 tap，假目标）、开盖主机（风扇停转，可 tap）、墙钟（可 tap）、电源插线板（可 tap）。
- **误导层**：
  - 玩家去修黑屏显示器（按开机键，错误）：Bug 哥吐槽「显示器：我冤啊，我好好的，是主机不给我饭吃！」
  - 玩家调墙钟（错误）：Bug 哥吐槽「钟都停 3 小时了，你调它干嘛？它今天放假！」
- **真相层**：把插线板插头重新插紧（drag 插头到插座）→ 主机风扇转起来 → 显示器亮起。真目标：主机断电。
- **Bug 哥台词**：
  - 误导时：「看见没！屏幕黑屏，经典故障！开机键按烂它！」
  - 真相：「等等，好像问题在我——黑屏只是『症状』，断电才是『病因』。」
- **Aha 设计**：插头插入瞬间，电流路径沿电线可视化点亮到主机再到显示器，症状与病因连线。

#### 示例关卡 6：《喊救命的工人》

- 关卡编号：42｜难度：★3｜Bug 日志：Bug042｜章节：05 公园·工地旁
- **场景**：工地围栏边。远处脚手架上工人 A 挥手大喊「帮帮忙！」，近处推车上堆满砖头、轮子卡在井盖缝里，推车工人 B 正在满头大汗。
- **物件清单**：脚手架工人 A（可 tap，假目标）、推车（轮子卡住，可 drag 抬轮子）、井盖（可 tap）、砖堆（干扰物，可 tap）。
- **误导层**：
  - 玩家跑去「救」工人 A（tap A，错误）：Bug 哥吐槽「A 师傅中气这么足，他是喊『帮帮忙搭把手』——他在等吊车，不在等我们。」
  - 玩家以为 A 被卡住，长按 A（错误）：Bug 哥吐槽「你再按下去，他该报警说有人骚扰了。」
- **真相层**：把井盖撬开一点（drag 井盖）→ 推车轮子从缝隙脱出 → 工人 B 顺利推走。真目标：卡在井盖缝里的推车轮子。
- **Bug 哥台词**：
  - 误导时：「救人如救火！冲！……等等，他好像在跟吊车师傅喊话，喊的明明是『帮帮忙往左一点』。」
  - 真相：「原来真正的 Bug 是我的思维——喊得最响的未必是最需要救的。」
- **Aha 设计**：音波可视化——工人 A 的喊话内容气泡显示「帮帮忙，往左一点！」，与吊车位置连线。

### 3.4 语言陷阱（puzzleType: language）

**定义**：玩家被文字/招牌/提示语的「字面意思」误导。真相是重新解读文字，或文字本身就藏着第二个意思。

**心智模型**：玩家快速扫读文字，抓住关键词（免费、半价、禁止），忽略修饰词、小字与双关。

**设计要点**：
1. 文字必须「在语法上完全正确」，误导来自玩家的快速阅读习惯。
2. 关键修饰词要用小字/不同颜色呈现，但必须可读（不能藏到看不见）。
3. 关卡内文字优先用中文，禁止英文生僻词。

#### 示例关卡 7：《第二杯半价》

- 关卡编号：35｜难度：★3｜Bug 日志：Bug035｜章节：04 商场·奶茶店
- **场景**：奶茶店。收银台广告牌写着「第二杯半价」，货架上有「原味奶茶」和「新品尝鲜·椰椰芋泥」。玩家拿着 1 杯原味 + 1 杯新品去结账。
- **物件清单**：广告牌（可 tap）、原味奶茶（可 drag 到收银台）、新品奶茶（可 drag 到收银台）、收银台（可 tap）、菜单（可 tap，干扰物）。
- **误导层**：
  - 玩家把「原味 + 新品」两杯放上收银台（错误）：Bug 哥吐槽「新品：您礼貌吗？半价写着『仅限同款』四个大字呢！」
  - 玩家反复看广告牌正面（错误）：Bug 哥吐槽「正面当然只有『第二杯半价』，小字在背面！商家的小心机！」
- **真相层**：tap 广告牌翻到背面 → 小字「仅限同款，新品除外」→ 把新品换回原味（drag 新品回货架，drag 第二杯原味到收银台）→ 结账成功。
- **Bug 哥台词**：
  - 误导时：「半价！冲！买它！……什么？新品不半价？那我买两杯原味不就完了，哈哈我真是天才！」
  - 真相：「等等，好像问题在我——我读书时学的不是阅读，是『扫读关键词』速成班。」
- **Aha 设计**：广告牌翻面动画，「仅限同款」小字放大弹出，与玩家的 2 杯奶茶形成勾选对比。

#### 示例关卡 8：《请点击红色按钮》

- 关卡编号：58｜难度：★4｜Bug 日志：Bug058｜章节：06 学校·机房
- **场景**：电脑机房。屏幕上只有一句话「请点击（不要点击）红色按钮」，下方有一个红色按钮和一个蓝色按钮。
- **物件清单**：红色按钮（可 tap）、蓝色按钮（可 tap）、屏幕文字（可 tap）、旁边的老师（干扰物，可 tap）。
- **误导层**：
  - 玩家读成「不要点击红色按钮」，于是点蓝色按钮（错误）：Bug 哥吐槽「我按蓝色了！怎么还报错？！这题是不是出错了！」
  - 玩家反复点蓝色（错误）：Bug 哥吐槽「蓝色：你礼貌吗？题目明明写的是『请点击红色按钮』，括号是给我看的注释！」
- **真相层**：点红色按钮 → 通关。真相：题目是「请点击红色按钮」，括号里的「不要点击」是 Bug 哥视角的注释——他在提示玩家「别被字面意思骗了」。
- **Bug 哥台词**：
  - 误导时：「『不要点击』那肯定不能点啊！老师没教过你『不要』的意思吗？……等等，好像问题在我。」
  - 真相：「原来真正的 Bug 是我的思维——我把注释当成正文读了。」
- **Aha 设计**：括号内容缩小变灰成「注释」样式，正文「请点击红色按钮」放大高亮。

### 3.5 细节推理（puzzleType: detail）

**定义**：场景中藏着一个「几乎看不见但符合逻辑」的细节，玩家需要主动调查（双击放大、慢放）才能发现。真相由细节推导而出。

**心智模型**：玩家扫一眼画面就下结论，忽略「多了/少了/变了」的微小差异。

**设计要点**：
1. 细节必须「存在且有逻辑」，不能是像素彩蛋（否则算强行解释）。
2. 必须配合「调查」能力引导（第一次双击目标物件时触发特写）。
3. 细节与误导结论形成「二选一」推理，让玩家感到「推理感」。

#### 示例关卡 9：《多出来的一只鸭》

- 关卡编号：68｜难度：★4｜Bug 日志：Bug068｜章节：07 医院·儿童区水池
- **场景**：儿童区小水池，7 只黄色橡皮鸭在水面漂着，玩家被告知「这里应该只有 6 只鸭」。
- **物件清单**：6 只黄鸭（可 tap）、1 只「黄鸭」浮在水草边（可 tap）、水草（可 tap）、旁边的小篮子（可 drag）。
- **误导层**：
  - 玩家一只只点黄鸭数数，数出 7 只（错误）：Bug 哥吐槽「1、2、3……7！就 7 只！管理员是不是不会数数？」
  - 玩家把水草边的「第 7 只」捞起来（drag 到篮子，错误）：Bug 哥吐槽「哎哟，这『鸭子』手感怎么有点不对……」
- **真相层**：双击（doubleTap）水草边的「第 7 只」→ 特写放大 → 它是一块做成鸭子形状的黄色海绵擦。真相：多出来的「鸭」不是鸭。
- **Bug 哥台词**：
  - 误导时：「数数还能错？1 2 3 4 5 6 7！铁证如山！管理员扣工资！」
  - 真相：「等等，好像问题在我——海绵擦：对，我是海绵擦，我装鸭子装得我自己都信了。」
- **Aha 设计**：特写镜头下海绵擦纹理逐帧清晰，与真鸭子并列对比，「材质」标签弹出。

#### 示例关卡 10：《电梯口的水渍》

- 关卡编号：85｜难度：★5｜Bug 日志：Bug085｜章节：09 城市夜景·写字楼大堂
- **场景**：写字楼大堂，电梯口地面有一串湿脚印通往门外，保安说「刚才明明没人出去」。玩家需要判断：谁留下的脚印？
- **物件清单**：湿脚印（可 tap 调查）、大门（可 tap）、门外的流浪狗（可 drag 门缝看）、角落的雨伞桶（可 tap）、监控屏（可 tap，干扰物）。
- **误导层**：
  - 玩家怀疑有人溜出去，反复查看监控屏（错误）：Bug 哥吐槽「监控 8 倍速看了 3 遍，连个鬼影都没有，保安要报警了。」
  - 玩家以为脚印是人穿的鞋（tap 脚印，错误）：Bug 哥吐槽「这脚印四个趾头开花，谁的脚长这样？葫芦娃？」
- **真相层**：drag 大门门缝 → 特写：门外趴着淋湿的流浪狗，爪印与脚印纹路一致 → 真相：是狗跑进来避雨又出去了。
- **Bug 哥台词**：
  - 误导时：「脚印！湿的！肯定有人偷溜！保安！查监控！……查完了，监控说：『你们人类真闲』。」
  - 真相：「原来真正的 Bug 是我的思维——我把『湿脚印』默认成『人的湿脚印』了。」
- **Aha 设计**：脚印纹路与狗爪放大对比重叠，重合度 100% 判定动画。

## 5. Bug 哥角色设计

### 5.1 角色定位与性格

Bug 哥是生活在现实世界缝隙里的有意识小 Bug 程序（见第 6 章世界观）。性格关键词：

| 性格 | 表现 |
| --- | --- |
| 自信 | 从不承认自己判断错，先甩锅给系统 |
| 嘴硬 | 被现实打脸后嘴硬 3 秒，再认错 |
| 搞笑 | 夸张比喻、谐音梗、自黑 |
| 爱装懂 | 用半吊子「专业知识」解释一切 |
| 嘴硬心软 | 嘴上吐槽，实际每次都会给玩家提示 |

招牌台词（铁律，必须在关卡中轮换出现）：

- 「这不是 Bug，这是隐藏功能。」
- 「等等，好像问题在我。」
- 「原来真正的 Bug 是我的思维。」

### 5.2 台词库（按场景分类）

| 场景 | 台词示例 |
| --- | --- |
| 关卡开场 | 「看见没！问题就摆在那儿，修它！」/「这波稳了，我一眼就看出 Bug 在哪！」 |
| 误导帮腔（确认玩家错误方向） | 「对！就是它！按它！……你按啊，怎么不动？」 |
| 错误反馈 1（首次） | 「嗯？没反应？肯定是系统的锅，不是我们的。」 |
| 错误反馈 2（重复） | 「等等，好像问题在我……要不我们再看看？」 |
| 无意义操作 | 「你点它干嘛？它就是个吃瓜群众。」 |
| 1 级提示 | 「别相信你的第一眼，看看别的。」 |
| 2 级提示 | 「注意那个不起眼的角落，它今天有点抢戏。」 |
| 3 级提示 | 「真相的逻辑我已经看穿了——是【关键条件】，你自己悟。」 |
| 胜利 Aha | 「原来真正的 Bug 是我的思维！……这次算你的！」 |
| 连败安慰 | 「别慌，牛顿都被苹果砸了好几次才开窍。」 |
| 章节 BOSS 关 | 「这关我服了，我认输，请老师傅（玩家）出山。」 |
| 隐藏关彩蛋 | 「你居然找到这里……看来你不是普通调试员。」 |

台词管理：全部台词走资源表（JSON），支持换肤变声与后续 IP 扩展，不硬编码在代码中（见 docs/05 数据层）。

### 5.3 Bug 哥成长（与玩家能力同步）

Bug 哥的性格随章节推进「收敛」，与玩家成长互为镜像：

| 阶段 | 关卡 | 性格状态 | 代表台词 |
| --- | --- | --- | --- |
| 见习期 | 1-20 | 嘴硬巅峰，逢锅必甩 | 「绝对不是我，肯定是系统的锅。」 |
| 初级期 | 21-50 | 开始自我怀疑 | 「等等，好像问题在我。」（首次承认） |
| 高级期 | 51-80 | 学会先观察后说话 | 「我学会先看再说话了，真的。」 |
| 首席期 | 81-100 | 坦然认错，收徒心态 | 「承认错误也是一种 Debug。」 |
| 觉醒期 | 101-105 | 找回身世记忆 | 「原来真正的 Bug 是我的思维。」（觉醒版） |

### 5.4 皮肤系统

> 解锁方式与定价以 09 文档 §5、`gd_skin` 种子数据为准（详见 docs/09）。

| 皮肤 | 主题 | 解锁方式 |
| --- | --- | --- |

## 6. 世界观

### 6.1 背景设定

现实世界其实是一个名为「现实系统」的超大程序：路灯、排队、电梯、奶茶店都有它们的「代码」。
普通人的眼睛只看到「现象」，而 Bug 哥能看到「现象背后不协调的逻辑」——即现实中的小 Bug。

玩家扮演「首席调试工程师」，是唯一能听见 Bug 哥说话的人，受 Bug 哥委托协助排查这些现实漏洞。
每修好一个漏洞，现实就「顺滑」一分，Bug 哥也离自己的身世真相更近一步。

### 6.2 主线悬念（三条线并行）

| 悬念 | 内容 | 关键节点 |
| --- | --- | --- |
| 身世之谜 | Bug 哥为什么是唯一有意识的小 Bug？他与「现实系统」的维护者有什么关系？ | 第 10 关剧情揭示「Bug 哥有一串读不懂的源码」 |
| 补丁组织 | 神秘组织「补丁」定期清理漏洞，Bug 哥一直在躲他们 | 第 60 关「补丁」首次现身并带走一只小 Bug |
| 世界真相 | 玩家在第 90 关发现，自己可能也是「现实系统」的一部分 | 第 90 关剧情反转，为第二部留钩子 |

## 7. 留存系统

### 7.1 剧情悬念（剧情驱动留存）

- 每 10 关一个章节剧情节点（过场动画/对话框），结尾必留悬念钩子。
- 三大悬念按第 10 / 30 / 60 / 90 关节奏推进，形成「追更感」。
- 章节 BOSS 关（每章第 10 关）附带特殊演出与 Bug 哥认输剧情。

### 7.2 成长能力（观察 / 调查 / 提示）

| 能力 | 效果 | Lv1 | Lv2 | Lv3 | Lv4 | Lv5 |
| --- | --- | --- | --- | --- | --- | --- |
| 观察 | 高亮可疑物件 | 提示文字 | 高亮 1 个物件 | 高亮 2 个 | 显示物件连线 | 直接标出异常点 |
| 调查 | 挖掘隐藏细节 | 双击显示物件名 | 显示物件描述 | 慢放 30 秒动画 | 特写镜头 | 显示「被隐藏的细节」线索 |
| 提示 | 提示系统 | 解锁 1 级提示 | 解锁 2 级提示 | 解锁 3 级提示 | 提示冷却减半 | 首条提示免费 |

- 成长材料：通关经验、Bug 日志收藏奖励、每日挑战奖励、激励视频额外奖励。
- 能力等级 = 长期目标，与 Bug 哥成长（5.3）互为镜像，形成「玩家变强 = Bug 哥变强」的情感绑定。

### 7.3 Bug 日志收藏（收集驱动留存）

- 每关通关解锁 1 条 Bug 日志，编号 Bug001 起连续递增（对应关卡编号）。
- 日志内容 = 本关「错误思路记录」：玩家当时的错误操作 + Bug 哥吐槽 + 真相一句话，可随时回顾。
- 章节套装：每章 10 条集齐解锁套装徽章与皮肤碎片。
- 收集率是隐藏关开启门槛之一（见 7.4）。

### 7.4 隐藏关彩蛋（惊喜驱动留存）

开启条件（需同时满足）：

1. 主关卡 1-100 全部通关；
2. Bug 日志收集率 ≥ 80%；
3. 累计触发 3 个隐藏彩蛋行为。

彩蛋行为示例：

| 行为 | 位置 | 奖励 |
| --- | --- | --- |
| 连续失败 3 次后，连续点击 Bug 哥 5 次 | 任意关卡结算界面 | 「嘴硬如铁」徽章 |
| 在选关界面长按章节标题 3 秒 | 选关界面 | 章节隐藏台词彩蛋 |
| 对「补丁」组织徽章长按 3 秒 | 第 60 关 | 剧情碎片「补丁档案」 |

隐藏关（101-105）内容：Bug 哥身世觉醒剧情 + 「觉醒 Bug」皮肤 + 封顶金币奖励。
